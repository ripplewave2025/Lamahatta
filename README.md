# 🏔️ Seemana Gaon — A Living Record

> *A digital platform documenting and empowering a small village in Lamahatta, Darjeeling.*

![Village Hero](public/village-hero.png)

## 🌍 About Lamahatta

**Seemana Gaon** is a small village of 22 houses and approximately 93 residents, nestled in the hills between 6th Mile and Takdah in Darjeeling, West Bengal, India. This website serves as a living record of our community — our economy, our challenges, our opportunities, and our vision for the future.

### 📍 Location
- **Region:** Lamahatta, Darjeeling District, West Bengal
- **Coordinates:** 27°04'28.9"N 88°21'03.6"E
- **Altitude:** ~1,800m above sea level
- [View on Google Maps](https://maps.app.goo.gl/QqA7aTt1YWLqjKMHA)

## 💼 Opportunity Gaps

These are the **unfilled needs** in our village economy — opportunities for investment and partnership:

| Sector | Status | Potential |
|--------|--------|-----------|
| 🏠 Homestay | Zero supply | Mountain views, authentic experience |
| ☕ Café/Restaurant | None | Tourist traffic, local demand |
| 🥾 Tour Guide | Informal only | Trekking, birding, cultural tours |
| 🌱 Organic Farming | Underutilized | Export potential, agro-tourism |

## 🛠️ Tech Stack

- **Framework:** [Next.js 15](https://nextjs.org/) with App Router
- **Styling:** [Tailwind CSS 4](https://tailwindcss.com/)
- **Animations:** [Framer Motion](https://www.framer.com/motion/)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Backend:** [Supabase](https://supabase.com/)
- **Deployment:** [Vercel](https://vercel.com/)

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/ripplewave2025/Lamahatta.git

# Navigate to the project
cd Lamahatta

# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.
